# Health Operating System (HealthOS)

The complete operating system for personal health inside NexaLife: preventive care, wellness, nutrition, sleep, mental wellbeing, medical organization, and long-term health planning. Written as the `NLB-HOS-*` series per `NLB-00` Article VII, occupying Volume 24.

Home domain: **LD-06 Health** (`NLB-03`). Catalogue anchor: **PU-06-001 – PU-06-046** (`NLB-04`).

**Scope boundary:** HealthOS is whole-person wellbeing. Training mechanics, athletic performance, and competition belong to the Fitness & Performance OS (`../fitness-performance-os/`), which emits workout, training-load, and recovery signals that HealthOS consumes as wellness inputs.
