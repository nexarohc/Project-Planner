# Fitness & Performance Operating System (FPOS)

Performance, training, progression, and competition — including the real-world (IRL) competition network. Written as the `NLB-FPOS-*` series per `NLB-00` Article VII, occupying Volume 25.

Home domains: **LD-06 Health**, **LD-11 Sports & Athletics** (`NLB-03`). Catalogue anchors: **PU-06-001–010**, **PU-11-001–014** (`NLB-04`).

**Scope boundaries.** FPOS is distinct from HealthOS (`../health-os/`), which owns whole-person wellbeing. FPOS is also *not* a second competition system: `NLB-14` (Community, Competitions & Achievement) defines the platform-wide competition, achievement, progression, and leaderboard framework, and FPOS is its sport-specific deep implementation.
